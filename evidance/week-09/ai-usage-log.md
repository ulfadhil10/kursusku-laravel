### Penggunaan AI

AI digunakan sebagai alat bantu selama proses pengerjaan dan pemeriksaan proyek KursusKu, dengan rincian sebagai berikut:

| No. | Aktivitas | Bentuk Bantuan AI |
|---|---|---|
| 1 | Pemeriksaan kode Blade | Membantu memeriksa struktur halaman pendaftaran dan elemen dropdown kursus. |
| 2 | Pemeriksaan JavaScript | Membantu menganalisis kode jQuery Ajax untuk menampilkan sisa kursi. |
| 3 | Perbaikan dependensi | Membantu mengidentifikasi package Bootstrap, jQuery, dan Axios yang belum terpasang. |
| 4 | Perbaikan Vite | Membantu menemukan bahwa file JavaScript belum dipanggil melalui direktif `@vite` pada layout utama. |
| 5 | Pengujian Ajax | Membantu memeriksa request availability melalui DevTools Network dan membaca respons JSON. |
| 6 | Dokumentasi | Membantu menyusun test matrix dan AI usage log sesuai panduan praktikum. |

### Hasil Penggunaan AI

Dengan bantuan AI, proses pemeriksaan dan perbaikan proyek menjadi lebih terarah. Fitur pengecekan sisa kursi menggunakan jQuery Ajax berhasil dijalankan dan menghasilkan respons JSON dengan status HTTP 200.

### Keterangan

AI digunakan sebagai alat bantu untuk analisis, pemecahan masalah, dan penyusunan dokumentasi. Pemeriksaan serta pengujian aplikasi tetap dilakukan secara langsung oleh mahasiswa.
